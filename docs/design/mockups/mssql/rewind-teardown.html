Rewind Plan GET /api/v1/deploy/rewind-plan

Fetched once on page load — describes each destructive playbook, doesn't execute anything.

Teardown leaves MSSQL installed
  1. Drop the Availability Group on both replicas (independently, CLUSTER_TYPE=NONE)
  2. Take AdventureWorks out of HADR if still flagged
  3. Drop the AdventureWorks database on both replicas
  4. Drop the Always On endpoint and AG certificate on both replicas
  5. Drop the database master key
  6. Remove AG certificate files, striped backups, seed backups, downloaded .bak
  7. Clear the controller-side backup/cert relay directories
Rewind leaves MSSQL installed
  1. Everything in Teardown, then
  2. Re-run site.yml against vm1 only: reconfirm config and restore a fresh AdventureWorks
  3. Leaves vm1 with a clean AdventureWorks and no AG — ready to retry backup/restore/alwayson
Reset Baseline removes MSSQL
  1. Stop mssql-server
  2. Remove mssql-server and mssql-tools packages and their yum repos
  3. Delete /var/opt/mssql, data_dir, log_dir, backup_dir
  4. Clear controller-side relay directories
  5. Host returns to a bare VM — call POST /install afterward to rebuild
